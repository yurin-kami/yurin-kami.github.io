# Golang 面试题：内存管理与 GC

这类题常出现在中高级面试，重点是理解性能问题背后的运行时机制。

## 1. 栈和堆有什么区别？

- 栈上的对象通常分配回收更快。
- 堆上的对象生命周期更灵活，但需要 GC 参与回收。

## 2. 什么是逃逸分析？

逃逸分析决定对象更可能落在栈还是堆：

- 生命周期短、作用域清晰，更容易留在栈上。
- 被外部引用或生命周期变长，更容易逃逸到堆上。

## 3. 三色标记法怎么理解？

- 白色：还没被扫描到。
- 灰色：已经发现，但引用对象还没扫完。
- 黑色：自己和引用对象都处理完了。

## 4. 为什么需要写屏障？

并发标记期间，对象引用关系会变化。写屏障用来通知 GC，避免还活着的对象被漏标。

## 5. 有 GC 为什么还可能内存泄漏？

因为 GC 只能回收“不可达对象”。如果对象还被引用，即使业务上已经没用，也不会自动释放。

## 速记版

- 栈快，堆灵活。
- 逃逸分析影响 GC 压力。
- 三色标记和写屏障是高频底层问法。
- 有 GC 也可能发生“可达但无用”的泄漏。
